POKÉAPI

Esta página web utiliza la API RESTful de Pokémon PokeApi.

Para obtener la imagen de Pikachu en movimiento se usa un fetch para obtener la imagen del archivo JSON que proporciona la API. Cuando buscamos un Pokémon se llama a una función usando Async/await que obtiene la imagen y las características del archivo JSON y se los pasa a otra función que crea el efecto de barra de progreso.

Con CSS se crea el efecto de apilamiento cuando consultamos varios pokémon o si añadimos varias veces el mismo pokémon y movemos la rueda del ratón varias veces hacia abajo.

Nombres de pokémon conocidos: Pikachu, Charizard, Mewtwo, Eevee, Gengar, Mew, Snorlax, Bulbasaur, Cetoddle, Drampa, Squirtle, Charmander, Charmeleon, etc.
